# Class Demo

### Features

- Adding a location
- Adding a visit manually
- Recording visits automatically (tracking)
- Displaying locations/visits
    - Showing heatmap
- Insights
    - Suggestions

---

### Draft Flow

1. Show the Map, empty
2. Show each of the screens briefly
3. Manually add in a demo location 
    - Pick something (XFinity Center)
4. Manually add a visit to the XFinity Center
5. Delete and load demo Db
6. Set Location to Target
7. Start tracking
8. Demonstrate the larger circles and heatmap
9. Show locations list
10. Show visits list
11. Show insights, letting user know where they spend most time at
    - Where they visit most
    - basic suggestions based on proximity and common visits
12. demonstrate the the automatic tracking grabbed users location and started a visit
13. Move user outside of visit to stop visit (Either just stop or reduce time it takes to depart)
