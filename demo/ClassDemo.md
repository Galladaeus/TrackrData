# Class Demo

### Features

- Adding a location
- Adding a visit manually
- Recording visits automatically (tracking)
- Displaying locations/visits
    - Showing heatmap
- Insights
    - Suggestions

---

### Draft Flow

1. Show the Map, empty
2. Show each of the screens briefly
3. Manually add in a demo location 
    - Pick something (XFinity Center)
4. Manually add a visit to the XFinity Center
5. Delete and load demo Db
6. Show insights, letting user know where they spend most time at
    - Where they visit most
    - basic suggestions based on proximity and common visits
7. Set Location to Target
    - This is where I demonstrate active user tracking, but not background
9. Start tracking
    - Wait for first ping and then show it shows where user is,
    - Move one location
9. Demonstrate the larger circles and heatmap
10. Show locations list
    - Shows some data, most visited, last visit
11. Show visits list
    - How long you were there, day you were there
12. demonstrate the the automatic tracking grabbed users location and started a visit
13. Move user outside of visit to stop visit (Either just stop or reduce time it takes to depart)
14. Show the updated insight target and safeway
